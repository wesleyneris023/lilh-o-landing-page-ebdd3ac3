# Lilhão Landing Page

Crie uma landing page moderna, bonita e responsiva para a lanchonete Lilhão. Desenvolva apenas o visual da página inicial, com identidade visual marcante, cores que despertem apetite, banner principal com o nome Lilhão, botão “Ver Cardápio”, seção de produtos em destaque com imagens, preços e botão “Fazer Pedido”, além de contato e rodapé. Design mobile-first, profissional e intuitivo. Use produtos e textos provisórios apenas para a demonstração visual. Não crie painel administrativo, banco de dados, autenticação ou funcionalidades complexas neste momento. Mantenha o projeto simples para economizar créditos.
